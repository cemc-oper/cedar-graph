# Workflow recipe products

Built-in recipes live under `cedar_graph/recipes/workflow/cn/` and follow the
cedarkit-plots v3 workflow schema. Product IDs are selected through
`select_workflow_product`; caller-supplied recipe files use the same compiler
and provider contract. See {doc}`../tutorials/recipe_v3` for the recipe format.
